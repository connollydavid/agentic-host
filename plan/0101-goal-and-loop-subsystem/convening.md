# plan/0101 convening record: two sittings of the cast

First sitting 2026-10-18: design review of the initial proposal. Second
sitting the same day, operator-charged: the design must be an idiomatic
extension of the host methodology, not over-fit to how other implementations
function. Rulings as returned, condensed; the full texts live in the session
that convened them.

## First sitting (design review)

- **Mara**: the direction split is right with one thief in it; "sanctioned
  next move" launders intent through a picker function, so suggest, never
  sanction, and show the frontier. One goal per tree if mid-goal maintenance
  is a sanctioned path. The emission needs the PURPOSE line (the why, not
  the number) and a NEEDS YOU line; same shape every time; fail loudly.
  The idle refusal must distinguish your-work-broke-it from already-red.
  Semantic acceptance needs one ack line on the closure receipt.
- **Wren**: compaction injection is a half cure; the trace still dies unless
  the record bank carries decisions and rejections. One move is right-sized
  but needs the acceptance surface and a sanctioned escape move (the
  pre-formed stop-and-ask). No park means temporary blocks get recorded as
  exits. goal set with no agent-side propose path rebuilds the original sin.
  Determinism without a when-judged marker hides staleness. Weak-model
  acceptance belongs at the start, not as dessert.
- **Fen**: goal complete is the reward verb; a weak model runs it early,
  reruns it, then invents a force flag. The refusal must be a full no-op and
  every mutating verb's failure re-prints the frontier. A wall of hazards is
  not actionable; ordered, first fix only, rest counted. Enforce
  operator-only in the tool or drop the claim. The seam needs one installer
  verb and a dead-hook check. Success must bank the receipt and print the
  next move.
- **Bly**: old tools rewriting the stamp must carry unknown keys forward or
  a routine materialize erases the goal. The record must be legible without
  the new verbs; the verb cannot be the hidden state. Closure receipts write
  once, atomically, at green. Abandon that only clears the key makes the
  deferral vanish; write a tracked OWED line. A seam on an old tool
  rebuilds the unknown-command bug with more steps; version-check and print
  the install command.
- **Orin**: write the spine against the CLI contract; the emission is the
  loop's whole interface. Two breaches of the host#26 constraint: a refusal
  decided in the seam, and validation born in plugin tools; the seam may
  only render what the CLI produced and shell to it. The purity claim is
  false if CI verdicts read live network; a tracked active-goal key dirties
  every worktree's verify. Claude parity must be executed, not asserted.

## Second sitting (idiom fidelity)

- **Mara**: the sidecar TRANSLATES to a tracked Status-line declaration,
  sidecar demoted to a per-worktree projection (the envhash pattern). The
  token CUTS: the audited commit is the act. park/unpark CUT as verbs,
  TRANSLATE as the queue. NEEDS YOU KEEPS as projection only, every line
  tracing to a tracked row. Over-fit named: the token, the BDI commitment
  moves, compaction re-injection where the corpus already answers; defer
  the whole OpenCode seam until the core is housegrown.
- **Wren**: recitation TRANSLATES to the declared corpus; what is not
  loaded does not exist, and the goal declaration belongs on a
  corpus-declarable tracked surface. Plugin tools TRANSLATE to the shipped
  MCP server; the duplicate surface is the port defect. Emission labels
  TRANSLATE mostly: NEEDS YOU is a HAZARD line, FRONTIER is the tasks line
  verbatim, CI is gate output; new labels only where no shape exists. A
  second goal state VIOLATES the plan record as single source; the equation
  goal IS milestone is the most idiomatic thing in the design.
- **Fen**: the refusal TRANSLATES back to the house shape: one HAZARD line
  per missing thing, each with the exact command; first-only-plus-count is
  progressive disclosure, a foreign interactive habit. The sidecar is the
  stamp idiom, two values, with show the only reader and repair the
  reconciler. Inline class markers TRANSLATE away: batteries showed the
  model transcribes decorations into the shell; the section is the class,
  command lines stay bare. propose KEEPS: the usage-emission idiom.
- **Bly**: the gitignored pointer VIOLATES as designed (invisible to a
  fresh clone, silent under-report on loss); the declaration is tracked,
  sidecar a projection. OWED TRANSLATES to PLAN.md's closure queue, where a
  cold reader looks first. Parked state in the sidecar VIOLATES; parked is
  standing, standing is tracked. The ledger entry needs applies-alone, the
  stamp migration with re-stamp command, and sidecar re-derivation.
  Degraded means legible without any verb.
- **Orin**: the MADR form KEEPS (call/0060 precedent; a plan without a
  call/ record orphans a spine-wide decision). State TRANSLATES by
  volatility: envhash is untracked because machine, receipts tracked
  because facts; the sidecar never holds what a clone must see. The gate
  deferral CUTS: compose as subprocesses, the tool driving its own verbs;
  shipping a weak gate writes a contract that only models the path walked.
  Parking TRANSLATES to re-queuing. The MCP server and the corpus are the
  seams; CUT the plugin tools and the compaction hook. The teaching section
  never says new, replaces, or migrate; the lineage lives in call/ alone.

## Synthesis adopted by plan/0101

The volatility split; no token; parking as re-queuing; subprocess gate
composition; all hazards each with a command; sections as classes; house
shapes in the emission; MCP and corpus as the seams; call/0061 as the
modality record; the lineage in the record layer.
