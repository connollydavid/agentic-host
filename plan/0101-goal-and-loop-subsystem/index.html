plan/0101: the goal and loop subsystem

Status: cut and in build (operator ruling 2026-10-18: build it, after a; active goal since 2026-10-19 — parked (the composed gate holds on host-lint's kani lane (cancelled at its pin, host-lint thirty-two); resume when that lane greens) since 2026-10-20 reflection pause because it is core functionality; second ruling the same day: the design must be an idiomatic extension of the host methodology, not a port of foreign implementations). The modality itself is call/0061; this plan executes it.

Why

The agent loop (orient, claim, work, bank a receipt, pass the gate) and any goal layer exist today as prose discipline plus scattered verbs. In a live session an operator invoked /goal complete plan/0007 in a harness where no such command existed; it arrived as prose and the agent improvised a receipt-less channel (host#26). The operator ruled the ambition larger than the plugin that issue proposes, and then ruled its form: housegrown first.

Decision (the idiomatic form)

A goal is a plan/NNNN milestone. No new artifact class exists to drift from the record.

State splits by volatility, the house's own division: durable facts are tracked surfaces the tool already authors (the milestone Status line, [receipt "goal"] stanzas in .host-lifecycle-receipts, OWED entries in PLAN.md's closure queue), and machine state is a gitignored .host-goal sidecar holding only this worktree's execution claim, re-derivable by goal repair from the tracked record. A lost sidecar under-reports nothing: the tracked declaration stands. One active goal per repo, because the tracked record is singular; the sidecar is the per-worktree claim on it.

Verbs (single words, fail closed, usage on bad args, the tasks and next family shape):

  • goal set <plan/NNNN> writes the Status-line declaration and a receipt stanza, and refreshes the sidecar. No authority token: the audited commit of the declaration is the act, and the operator-ruling line names whose hand it was. The agent-side path is goal propose, which prints the command and never mutates.
  • goal show is the orientation emission: labeled lines in fixed order (PURPOSE, GOAL, POSITION, NEEDS YOU, CI, FRONTIER, TREE, NEXT), reusing house shapes wherever they exist (NEEDS YOU is a HAZARD line that each trace to a tracked row and name the ask; CI is gate output; FRONTIER is the tasks ready-frontier line verbatim), the exact bare command alone on the last line, no inline execution-class markers (the section a move prints under is its class; command lines stay bare), a pure function of the working tree with no clock, and a loud refusal on unreadable state.
  • goal park --reason / goal unpark are re-queuing, not a state machine: they write the Status line and the closure-queue entry and a receipt. A temporary block never gets recorded as an exit.
  • goal abandon --reason appends the closure-queue OWED entry through the tool, writes the Status line and a receipt, and clears the sidecar. Debt lives where a cold reader looks first.
  • goal repair <plan/NNNN> reconciles toward the tracked record and re-points a renamed plan, refusing ambiguity, with a receipt.
  • goal complete <plan/NNNN> composes the existing gates as subprocesses (the tool invoking its own verbs and reading their exits; HAZARD lines pass through intact): the full verify sweep, equal to what the verify skill runs (the software gate, the ci judge, book --check, the refs gate, and obligations per discovered spec), then task receipts for the milestone, the tree clean with nothing unpushed, and the PLAN.md row. No gate is weakened and none is duplicated; the tool runs its own verbs, host#26's constraint applied inward. A refusal is a full no-op; every hazard prints, ordered, each with its exact fix command (the verify-setup shape, not progressive disclosure); success writes one atomic [receipt "goal"] stanza, updates the Status line, and prints the next move or the no-goal state.

The install is a generated door family, folded in early (the operator's ruling). The install verb owns the front doors as one source inside the binary and emits the per-harness renderings: flat, hyphenated /host-<verb> doors (/host-goal, /host-tasks, /host-ci) for OpenCode and Claude alike, each injecting its verb's emission and closing with the re-orient link; install --check guards the files against hand edits with the regenerate remedy. The universal-form ruling behind it: the spine states the token once, and each harness's sigil is chrome. Goal tools join the shipped MCP server (harnesses mount MCP natively), the goal declaration becomes readable as a corpus surface (the plan/0083 shape, the house's always-loaded mechanism, which is the recitation answer). Plugin custom tools stay cut (a duplicate tool surface), the compaction hook stays cut (the corpus is the recitation), and the kick stays unruled: the install renders and never actuates.

Contract closure (the final consult, 2026-10-19)

The final-design consult ran the cast and a blind external bench over the settled form. The cast: Mara signed off (the real-output rerun tracked, not blocking); Wren signed off short of a watched item (a window cut that keeps NEXT but drops PURPOSE loses the why; watched at the fen rerun, not pre-fixed); Fen signed off conditional on the rerun passing with a resolved key on the last line; Bly refused until two holes were answered; Orin signed off with two wording amendments. The bench (transcript: bench/codex-final-design-2026-10-19.txt) ruled the shape sound, freeze not yet, four blockers. The rulings that follow close them.

  • Authority order, stated once: receipt stanzas over the Status line over the sidecar. A crash between writes reconciles downward by goal repair; no journal is owed because the authority order makes every partial state recoverable by re-derivation.
  • The no-op defined: the sweep's composed gates are check-mode verbs that write nothing; a refusal forbids every write, including the sidecar. The only writes the verb ever makes are the closure's own receipt and Status line, after all gates pass.
  • The closure names its own commit: complete demands a clean tree and then dirties it with exactly two files; the success output names both and the commit-and-push that follows (landed in the component, cd440d8).
  • A divergent sidecar is a hazard: absent is no claim (fine); a claim on another goal while the closure names this one refuses with the repair remedy (landed, cd440d8). Park's tracked trace is built as ruled: the receipt stanza and the Status transition, never sidecar-only.
  • The offline boundary: the sweep runs no network; the unpushed count reads the local remote-tracking ref, which can itself be stale, and the emission's revision-unbound label is the standing disclosure of that class.
  • The last line is never placeholder-shaped: every NEXT line carries a resolved key or a runnable command as printed (Fen's ruling); the emission asserts it.
  • Spine wordings (Orin): the spine states the closed verb list the binary enforces, with ASD-STE100 as provenance of the list, not the rule; and it names the sidecar-authority boundary as the checkable form (no verb reads the sidecar as authority) rather than the rationale word. The door family is data the adopter owns: a third harness is an edit, not a fork.

The freeze bench (transcript: bench/codex-freeze-bench-2026-10-19.txt) ruled the outputs coherent and named three blockers, all now closed. The crash window is steel: a complete or abandon receipt whose Status transition never landed reads as an unresolved closure and repair finishes the write (component bf0e7a3). The owed lifecycle takes the bench's minimal rule: the row names its owner, discharge is evidence recorded on the row, and owed work never outranks the active goal unless that goal depends on it (the design text's outranking claim is corrected here; the v1 code never implemented it). And revision binding was never absent from the gate: the composed ci judge compares receipts against the judged revision (the live refusal shows that hazard firing), so the revision-unbound label is display honesty about the emission, not a gate gap. With the fen gate passed at sixteen of sixteen and the three blockers closed, the freeze stands. The teaching lines carry a measured scorecard (2026-10-20): the dokimi paired-arms run, subject qwen3.5-4b with qwen3.6-27b as judge, scored baseline 30.8 against profile 89.0 (paired delta +58.2, CI [+28.7, +87.8]); the instrument is adopted at tools/dokimi and the transcript files in the plan's bench.
