host-lint 0\.8.0: \--docs repo-wide prose lane, plus located, fix-hinted, tiered output

D1 (plan/0030): a single \--docs mode walks authored markdown only (git ls-files, honors .host-lintignore, skips code/symlinks), the counterpart to the naming \--all. E1-E4 (plan/0031): the prose output becomes weak-agent-fixable. Occurrence-mapping locates each tell at its real line:col (ten em-dashes no longer collapse onto the first line); a mechanical fix hint is keyed on the trope id; non-locatable whole-document diagnoses (density, anaphora, bullet patterns) drop to an advisory Note tier that does not gate, so clean-to-zero terminates. Case-insensitive matching keeps sentence-initial tells located. Golden tests \+ the obligations digest re-record. Co-Authored-By: Claude Opus 4\.8 \<noreply@anthropic.com\>
