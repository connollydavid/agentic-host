# AST-GREPFind Code by Syntax

ast-grep(sg) is a fast and polyglot tool for code structural search, lint, rewriting at large scale.

[Quickstart](/guide/quick-start)

[Intro](/guide/introduction)

[Examples](/catalog/)

[With AI](/advanced/prompting)

![ast-grep](./logo.svg)

-

  ---

  ## Search and Rewrite

  ast-grep is a code tool for [structural search and replace](/guide/quick-start). It is like syntax-aware grep/sed! You can write code [patterns](/guide/pattern-syntax) to locate and modify code, based on AST, in thousands of files, [interactively](/guide/tooling-overview#interactive-mode).

` ast-grep -p '$A && $A()' -r '$A?.()'  `

  ![](/image/search-replace.png)

-

  ---

  ## Scan as Linter

  ast-grep is a versatile and flexible tool for [linting](/guide/scan-project) code with AST patterns. You can easily add new customized rules with [intuitive syntax](/guide/rule-config) and enjoy pretty error reporting out of box.

` ast-grep scan  `

  ![](/image/yaml-scan.png)

-

  ---

  ## Programmatic Usage

  ast-grep also provides [node-js binding](/guide/api-usage/js-api) to access syntax trees programmatically. You can use jQuery like [utility methods](/reference/api#napi) to traverse syntax tree nodes. Node API also has opt-in [type safety](/blog/typed-napi).

`  npm install @ast-grep/napi `

  ![](/image/sg-napi.png)

## Performant

Blazing fast search and replace across thousands of source code files, powered by parallel Rust.

📚

## Polyglot

Supports many programming languages out of box! You can also register your own tree-sitter parsers by dynamic loading.

👟

## Progressive

Supports multiple forms of usages from one-line command to fully programmatic interface, scaling to different scenarios.

🛠️

## Pragmatic

Not a toy but a batteries-included tool with interactive codemod, language server and testing tool.
