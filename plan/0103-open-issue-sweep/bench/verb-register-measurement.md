# host#27 measurement: the name-verb register, taken from the corpus (2026-10-28)

Harvest: every `### <title> {#anchor}` task heading in `plan/*/README.md`, first
word lowercased, counted. The corpus speaks for itself:

- Verb-led titles exist and repeat: release (14), write (11 with compounds),
  implement (4), add (4), gather (3), validate (3), settle (3), update (2),
  re-pin (2), rule (2).
- Noun-led titles are the majority (the, cast, a, this, adversarial, fen,
  spine, msg-lane, ...): the imperative rule must not NAK them, so the ruling
  fires on the first word only when it is a *measured non-approved verb* or a
  numeral, never on mere non-membership.

So the register encodes two measured lists, not the licensed ASD-STE100 set:

- APPROVED: the verbs measured above, plus the goal verbs the house already
  ships (set, park, unpark, complete, install, show).
- NAKED, with alternatives: the live case the issue records, `drive` to `run`
  (2026-10-19, the anchor that went `#dogfood-loop` to `#run-the-loop` in an
  hour). The list grows by measurement, one collision at a time, the same way
  a LEXICON declaration lands.

The same measurement rules out a regex for "imperative": without a POS layer
the ruling keys on the measured lists, which is exactly how the house wants a
word list to behave.
