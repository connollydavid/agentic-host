## Settled design

1. **A `host-lint commit` verb** with explicit inputs: `--message <file>`,
   `--diff <file>`. The hook stages the diff to a file and calls the verb. The verb
   runs the existing message checks (subject escalation, body prose advisory) plus
   the duplication check. Fen's dissent is honored in ergonomics: the verb's help
   documents the exact re-run line, and the hook prints it on a warn.
2. **Duplication check, exactly as calibrated**: comment runs from added lines,
   markers stripped, sentence-split, normalized; a sentence of 8+ words appearing in
   the BODY (subject excluded) warns (exit 3). The warn wording names the safe
   direction: trim the message; keep the comment (Fen probe 1).
3. **Degraded path discloses (Bly)**: no `--diff` supplied -> the verb still runs
   the message-only checks and prints "duplication not checked (no diff provided)"
   beside the verdict — the refs-gate disclosure pattern; never a silent clean-as-
   if-checked.
4. **No precedent detector (unanimous, corpus-driven)**: the shape, the widened
   patterns, the measured zero, and the survivor-bias caveat are recorded in
   guidance, ready to cut a rule the day a real instance appears.
5. **Faults 2 and 4**: skill text, explicitly labeled not mechanized. Never
   VOCABULARY.md (the call/0046 property). Wording must survive a quantized read
   (Fen: qualifiers get dropped — lead with the imperative, not the caveat).
6. **Packaging**: one detector-precision milestone bundling fault 1 with the
   host-lint#24 LEXICON-carve-out remainder; one host-lint release at the hold
   lift. If the carve-out stalls at lift time, split (Mara's fallback, honoring
   Bly). Implementation proceeds now as held commits in the host-lint worktree.
7. **Owed before release**: the REAL Fen probes (prompts in fen-p1.txt /
   fen-p1-worded.txt / fen-p2.txt; runner fen-program.py) as the acceptance gate,
   replacing today's simulation; the milestone cut, the call/ record (with the
   substitution noted), and the ledger entry land at the hold lift.
